Kenapa butuh ini di GitHub Pages?

GitHub Pages hanya menyimpan file statis. Agar HP Guru Piket, HP Security, dan HP Siswa bisa sinkron otomatis tanpa reload, hubungkan ke Firebase Firestore gratis (Google).

Dapatkan gratis di: console.firebase.google.com → Project Settings → Your apps → SDK setup and configuration.
